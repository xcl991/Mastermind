# A little clarity, every day.

Selamat datang di **Mastermind** — ruang tenang untuk catatan, pengetahuan, dan ide yang saling terhubung.

Semuanya tinggal di perangkat Anda. File Markdown biasa, siap dibuka kembali dengan Mastermind atau editor Markdown favorit Anda.

> Pikiran yang baik tidak harus berdiri sendiri. Hubungkan satu ide dengan ide berikutnya.

## Satu ruang, banyak kemungkinan

- **Tulis dengan leluasa.** Pilih mode edit atau split untuk mulai menulis. Perubahan disimpan otomatis.
- **Temukan koneksi.** Tulis [[Knowledge graph]] untuk menghubungkan dua catatan.
- **Berikan konteks yang tepat.** Gunakan [[Token-efficient workflow]] untuk mengirim bagian yang relevan ke AI.
- **Bawa pengetahuan Anda.** Baca [[Mastermind compatibility]] untuk membuka vault yang sudah ada.

## Mulai dari sesuatu yang kecil

Buat catatan baru, tuliskan sebuah ide, lalu hubungkan dengan sesuatu yang sudah Anda ketahui. Graph akan tumbuh bersama pemikiran Anda.

Lihat [[Projects/Mastermind roadmap]] untuk arah proyek ini, atau [[Architecture/Local-first]] untuk memahami bagaimana data disimpan.

---

**Tip:** gunakan ⌘ K / Ctrl K untuk mencari, dan ⌘ S / Ctrl S untuk menyimpan sekarang.
